# CDNTR

**CDNTR** ([cdn.com.tr](https://cdn.com.tr/en)) has served customers since 2013 and is one of Türkiye's first
CDN providers. One platform for delivering and running web applications:

- **CDN and edge caching**, with HTTP/3, Brotli and edge image optimization (AVIF and WebP)
- **Edge security**: WAF, DDoS protection, bot protection, rate limiting
- **DNS and automatic SSL**
- **Managed WordPress and PHP hosting**
- **Managed Container Apps**: deploy a folder, a Docker image or a `docker-compose.yml`, with managed
  Postgres, MySQL, Redis and NATS add-ons
- **S3-compatible object storage**
- **[`cdnctl`](https://github.com/mediatriple/cdnctl)**, a command-line tool and public API for all of it

Your data stays in the region you choose (Türkiye, Europe or the United States), with a Türkiye-only
processing option, and a data processing agreement on request.
